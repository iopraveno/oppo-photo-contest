# Obrázky webu

Sem patří soubory od OPPO. Web si je načte sám, nic dalšího není potřeba nastavovat.
Dokud soubor chybí, web místo něj ukáže jednobarevnou plochu nebo text.

## Logo a velké fotky

| Soubor | Kde se použije |
| --- | --- |
| `oppo-logo-white.png` (nebo .svg) | logo v hlavičce a patičce (na tmavém pozadí), už nahráno |
| `oppo-logo.png` (nebo .svg) | logo na světlém pozadí, už nahráno |
| `oneplus-logo.png`, `oneplus-logo-white.png` | logo OnePlus u ceny Shot on OPPO a v patičce, už nahráno |
| `hero.jpg` | velká fotka v úvodu, na šířku, min. 2400 px (ideálně západ slunce nebo zimní světlo) |
| `community.jpg` | fotka za sekcí „Komunita rozhoduje“, na šířku |

## Ukázky k soutěžním tématům (nejdůležitější)

Každé téma má jednu hlavní fotku a volitelně další ukázky. Všechny z Hasselblad fotoaparátu OPPO.

| Téma | Hlavní fotka | Další ukázky (volitelné) |
| --- | --- | --- |
| Zlatá hodina a západy slunce | `temata/zlata-hodina.jpg` | `temata/zlata-hodina-2.jpg`, `-3.jpg` … |
| Modrá hodina a světla města | `temata/modra-hodina.jpg` | `temata/modra-hodina-2.jpg` … |
| Mlha, inverze a první mráz | `temata/mlha.jpg` | `temata/mlha-2.jpg` … |
| Detaily z dálky (zoom) | `temata/zoom.jpg` | `temata/zoom-2.jpg` … |

Fotky na šířku i na výšku jsou v pořádku, web je ořízne.
